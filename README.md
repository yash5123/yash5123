## 🚀 What I've Built

<table>
<tr>
<td width="50%" valign="top">

### 🌍 TourVibe
**Tourism Intelligence Platform**

Upgraded a Python/Streamlit sentiment prototype into a production-grade full-stack platform. Visitors leave feedback; the platform scores it with HuggingFace NLP models, surfaces trends, and gives destination managers real insight into what travelers actually feel.

`Next.js 14` `Node.js` `MongoDB Atlas` `HuggingFace` `Express`

*IDP Project · Ramdeobaba University*

</td>
<td width="50%" valign="top">

### 💧 DroughtGuard
**Civic Drought Risk Dashboard**

Tracks drought risk across **732 Indian districts** using a composite index built from rainfall anomalies, NDVI satellite data, and soil moisture. District officers can drill down to see exactly where water stress is building — before it becomes a crisis.

`React` `Express` `MongoDB Atlas` `GIS Data`

*Civic Tech · Water Resource Management*

</td>
</tr>
<tr>
<td width="50%" valign="top">

### 🏥 MediCare
**Personal Health Tracker**

A health tracking app with animated vitals, skeleton loaders, and a fully custom design system built from scratch with CSS tokens. Handles auth, image uploads, and persistent health records — all wrapped in a UI that actually feels good to use daily.

`Next.js 14` `TypeScript` `shadcn/ui` `NextAuth.js` `Cloudinary`

*Health Tech · Full Design System*

</td>
<td width="50%" valign="top">

### 🌱 Verdi
**Carbon Footprint Tracker**

Built at a hackathon — tracks individual carbon footprints and turns sustainability into a game. Features a Live Campus Pulse, Carbon DNA fingerprint per user, Green Contract staking, and a shared virtual city that grows as the community goes greener.

`React` `Node.js` `MongoDB`

*Hackathon Build · Campus Sustainability*
